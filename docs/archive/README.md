# 历史设计归档

本目录保存阶段性设计、排障记录和特定 workspace 的实验文档。这些内容对理解项目演进有价值，但不是新用户启动项目所需的主路径。

归档文档的维护规则：

- 可以公开，但不能包含真实密钥、真实 App ID、真实用户聊天内容或私有业务数据。
- 新开发者优先阅读 `docs/requirements.md`、`docs/prd.md`、`docs/high-level-design.md`、`docs/detailed-design.md`。
- 归档文档中的设计可能已被当前代码替代，以当前源码和主文档为准。
- 包含真实实例路径、真实会话 ID 或私有用户上下文的排障报告不随开源仓库发布。
